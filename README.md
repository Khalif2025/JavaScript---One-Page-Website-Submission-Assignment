# 📸 One Page Website with Lightbox Gallery

This is a simple **One Page Website** featuring an **image gallery** with a **lightbox (modal) effect**. Clicking an image enlarges it in a modal for better viewing.

## 📌 Features
- 🌆 **Dynamically Fetched Images** – Uses Unsplash for high-quality images.
- 🔍 **Lightbox Modal** – Click an image to open it in full view.
- 🎨 **Responsive Design** – Works well on different screen sizes.

## 🛠️ Tech Stack
- **HTML** – Structure of the website.
- **CSS** – Styling and responsiveness.
- **JavaScript** – Lightbox functionality.
